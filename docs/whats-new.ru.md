# Что нового

Последние изменения в этом руководстве пользователя. С вопросами обращайтесь по адресу <support@unbiodiversitylab.org>.

!!! note
    Некоторые из этих обновлений пока доступны только на английском языке; перевод выполняется.

## Ноябрь 2026 года

- **Обучающие видео** на большинстве страниц [руководства по публичной платформе UNBL](unbl-public-platform/index.md). Откройте блок с видео в начале страницы.
- **Новые показатели** описаны в разделе [Какие динамические показатели доступны для моей страны/области, представляющею интерес?](unbl-public-platform/8_dynamic_metrics1.md): Protected Connected Index, Coastal Eutrophication и морской показатель. Сводные данные по показателям теперь можно скачать и в формате `.tsv`.
- В разделе [Как мне вырезать и экспортировать наборы данных?](unbl-public-platform/15_clip_export.md) теперь описано, как скачать границы страны в формате GeoJSON.
- **Руководство по ELSA**: «ограничения по площади» теперь называются **целевыми показателями по площади**; обновлены снимки экрана и добавлено описание того, как свернуть окно анализа. См. [Редактирование анализа ELSA](elsa/05_editing_analysis.md).
- **Руководство по рабочим пространствам**: обновлены главы 1–6, в том числе о [добавлении мест](unbl-workspaces/5_add_places.md) и [добавлении собственных данных](unbl-workspaces/6_add_data.md).
- [Обзорный документ о хранении данных](unbl-workspaces/data_security.md) теперь доступен в меню рабочих пространств.
- На каждой странице указана дата последнего обновления, а при наведении курсора на сокращения, например ELSA или ГПБ, отображается их расшифровка.

## Июнь 2026 года

- Новый раздел: [Добавление собственных пользовательских показателей в ваше рабочее пространство](unbl-workspaces/7_custom_metrics.md).

## Январь 2026 года

- Новый [обзорный документ о хранении национальных данных, добавленных в рабочие пространства](unbl-workspaces/data_security.md), на всех пяти языках.

## Ноябрь 2025 года

- В руководстве по ELSA теперь объясняется, как карты действий ELSA поддерживают иерархию мер по достижению нейтрального уровня деградации земель (LDN) в рамках Конвенции ООН по борьбе с опустыниванием (UNCCD). См. [Для чего предназначен инструмент ELSA](elsa/02_tool_purpose.md).
- Новое [руководство по защищенным рабочим пространствам UNBL](unbl-workspaces/index.md).
