# Доступ к данным UNBL в ArcGIS Pro (STAC)

Платформа UN Biodiversity Lab (UNBL) публикует свои растровые наборы данных через STAC API. Если вы являетесь участником рабочего пространства UNBL, вы можете подключить ArcGIS Pro к этому API, выполнять поиск в каталоге и добавлять растры UNBL на карту, не загружая их предварительно.

На этой странице описано, как настроить подключение и чего ожидать от добавленных слоев.

## Что нужно для начала работы? {#chto-nuzhno-dlya-nachala-raboty}

- **Учетная запись UNBL, входящая в рабочее пространство.** Выполнять поиск в каталоге может любой, но открывать сами данные могут только участники рабочего пространства. Чтобы запросить рабочее пространство, см. раздел [Как мне запросить рабочее пространство UNBL?](1_basics.ru.md#kak-zaprosit-rabochee-prostranstvo-unbl)
- **Учетные данные**, по которым UNBL определяет, кто вы: токен API или ключ API (см. следующий раздел).
- **ArcGIS Pro 3.5.3 либо 3.6 или более поздней версии.** В более ранних версиях 3.x есть известная ошибка STAC (Esri BUG-000164564), из-за которой слои не загружаются и появляется сообщение *Failed to add data: Unknown error*.

!!! note
    Учетные данные нужны для всех наборов данных, в том числе отмеченных как общедоступные. Если вам нужна только копия глобального набора данных, см. раздел [Как мне загрузить необрезанные глобальные наборы данных?](../unbl-public-platform/16_download_global_data.ru.md)

## Как получить учетные данные? {#kak-poluchit-uchetnye-dannye}

Вы можете использовать один из двух видов учетных данных:

| Учетные данные | Срок действия | Лучше всего подходит для |
|---|---|---|
| **Ключ API** (API key) | Не истекает | ArcGIS Pro и других настольных ГИС-программ |
| **Токен API** (API token) | Около одного часа | Однократной проверки подключения или коротких задач |

Для ArcGIS Pro мы рекомендуем ключ API: его достаточно ввести один раз, и его не нужно заменять каждый час.

### Как запросить ключ API {#kak-zaprosit-klyuch-api}

1. Напишите на адрес <support@unbiodiversitylab.org> и запросите ключ STAC API для ArcGIS Pro.
2. Укажите адрес электронной почты вашей учетной записи UNBL и название вашего рабочего пространства.
3. Храните полученный ключ в тайне. Любой, у кого он есть, может открыть данные, доступные вашему рабочему пространству.

### Как получить токен API {#kak-poluchit-token-api}

1. Откройте STAC Browser UNBL по адресу <https://stac.unbiodiversitylab.org>.
2. Нажмите **Login** (Вход) и войдите со своей учетной записью UNBL. Если у вас еще нет учетной записи, нажмите **Login**, затем **Sign up** (Регистрация) и подтвердите учетную запись по ссылке из полученного письма.
3. Нажмите **API token** (токен API) в том же ряду кнопок, что и **Login**.
4. В открывшейся панели убедитесь, что у вашей учетной записи есть доступ к рабочему пространству. Если доступа нет, данные не откроются в ArcGIS Pro.
5. Скопируйте токен. В панели также указано, когда истекает срок его действия.

Дополнительные технические сведения, в том числе о доступе из Python и GDAL, см. на [странице доступа к API UNBL](https://stac.unbiodiversitylab.org/api-access.html) (на английском языке).

## Как подключить ArcGIS Pro к STAC UNBL? {#kak-podklyuchit-arcgis-pro-k-stac-unbl}

1. В ArcGIS Pro на вкладке **Insert** (Вставка) нажмите **Connections** (Подключения), затем **STAC Connection** (Подключение STAC), затем **New STAC Connection** (Новое подключение STAC).
2. В поле **Connection** (Подключение) введите `https://stac.api.unbiodiversitylab.org/`
3. Оставьте поле **STAC API Authentication** (Аутентификация STAC API) пустым. Здесь ArcGIS Pro предлагает только вход через Microsoft Azure, который UNBL не использует.
4. В разделе **Custom Headers** (Пользовательские заголовки) добавьте один заголовок:
    - С **ключом API**: ключ `X-API-Key`, значение: ваш ключ API.
    - С **токеном API**: ключ `Authorization`, значение: `Bearer`, пробел, а затем ваш токен (например, `Bearer eyJhbGci...`).
5. Оставьте поле **Cloud Storage Connections** (Подключения к облачному хранилищу) пустым.
6. Нажмите **OK**, чтобы сохранить подключение.

!!! tip
    Копируйте и вставляйте учетные данные прямо в диалоговое окно ArcGIS Pro. Токен API очень длинный (около 5700 символов), и некоторые программы, например окно терминала, при вставке незаметно обрезают длинный текст. Обрезанный токен вызывает ту же ошибку, что и просроченный.

!!! warning
    Держите в ArcGIS Pro **только одно** подключение к STAC UNBL. Старая копия подключения может оставаться выбранной и продолжать отправлять просроченные учетные данные. Если вам нужен новый токен, измените существующее подключение, а не создавайте второе.

## Как добавить слои UNBL на карту? {#kak-dobavit-sloi-unbl-na-kartu}

1. Откройте панель **Explore STAC** (Обзор STAC) и выберите подключение UNBL в раскрывающемся списке.
2. На вкладке **Parameters** (Параметры) выберите нужную коллекцию.
3. Нажмите **Select assets** (Выбрать ресурсы) рядом с коллекцией и отметьте ресурсы (файлы), которые хотите добавить.
4. Выполните поиск.
5. В результатах добавьте нужные элементы на карту.

!!! note
    ArcGIS Pro фиксирует выбранные ресурсы в момент выполнения поиска. Если вы измените ресурсы, выполните поиск снова.

## Как долго сохраняются слои? {#kak-dolgo-sokhranyayutsya-sloi}

Слои, добавленные из STAC UNBL, являются **временными**. Каждый слой открывается по защищенной ссылке, срок действия которой истекает примерно через **два часа** после того, как UNBL ее выдал (на практике — примерно через 1 час 45 минут – 2 часа 15 минут после добавления слоя). Использование ключа API этого не меняет.

| Задача | Нужны ли учетные данные? |
|---|---|
| Поиск в каталоге | Нет |
| Добавление результата поиска на карту | Да |
| Повторная отрисовка слоя, добавленного менее двух часов назад | Нет |
| Повторное открытие слоя, сохраненного в проекте ArcGIS Pro | Невозможно: выполните поиск и добавьте элемент снова |

После истечения срока действия ссылки слой перестает отображаться. Чтобы продолжить работу, выполните поиск и добавьте элемент снова.

!!! tip
    Чтобы сохранить набор данных на более долгий срок, загрузите файл GeoTIFF, пока ссылка еще действительна, и добавьте его в ArcGIS Pro как локальный растр.

## Что означают эти сообщения об ошибках? {#chto-oznachayut-soobshcheniya-ob-oshibkakh}

| Сообщение об ошибке | Вероятная причина | Что делать |
|---|---|---|
| `401 Invalid token` или `401 Token expired` | Токен обрезан, введен с ошибкой или просрочен | Получите новый токен и вставьте его прямо в подключение |
| `401 Invalid API key` | Ключ API неверен или отключен | Проверьте значение `X-API-Key` или напишите на <support@unbiodiversitylab.org> |
| `HTTP error code : 404` для пути, начинающегося с `/vsiaz/` | Учетные данные не дошли до UNBL | Проверьте запись **Custom Headers** в подключении |
| `403` для адреса, содержащего `blob.core.windows.net` | Срок действия защищенной ссылки слоя истек | Выполните поиск и добавьте элемент снова |
| `unsupported data type` с упоминанием `StacItemHref` | Выбрано старое или повторяющееся подключение | Оставьте одно подключение UNBL и выберите его в **Explore STAC** |
| `Failed to add data: Unknown error` | Известная ошибка ArcGIS Pro (BUG-000164564) | Обновите ArcGIS Pro до версии 3.5.3 либо 3.6 или более поздней |
| Пути по-прежнему начинаются с `/vsiaz/` после входа | Ваша учетная запись не входит ни в одно рабочее пространство | [Запросите рабочее пространство UNBL](1_basics.ru.md#kak-zaprosit-rabochee-prostranstvo-unbl) или попросите администратора вашего рабочего пространства добавить вас |

По другим вопросам пишите нам на <support@unbiodiversitylab.org>.
