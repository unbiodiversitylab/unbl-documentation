# Приложение 3: Журнал изменений слоев данных

На этой странице регистрируются изменения **слоев данных по умолчанию**, используемых Инструментом интегрированного пространственного планирования ELSA. Слои данных по умолчанию — это элементы планирования, фиксирующие ограничения (lock-in) и ограничения зонирования, которые ELSA предоставляет для нового анализа. Текущий набор приведен в [Приложении 2 - Слои данных](13_annex2.md).

Слои данных меняются со временем: исходные наборы данных обновляются создающими их организациями, появляются более качественные наборы данных, а способы подготовки данных для ELSA совершенствуются. Этот журнал изменений позволяет пользователям видеть, какие слои изменились, когда и почему, чтобы результаты, полученные в разное время, можно было корректно сравнивать, интерпретировать и цитировать.

!!! note "Примечание"
    Перечисленные здесь изменения применяются к **новым анализам**, созданным после даты изменения. Уже выполненные анализы сохраняют те слои данных, с которыми они были выполнены, и их результаты не пересчитываются. Чтобы использовать обновленные слои, создайте новый анализ.

## Как читать этот журнал изменений

Каждая запись описывает одно изменение одного слоя данных по умолчанию и относится к одному из следующих типов изменений.

| Тип изменения | Значение |
|---------------|----------|
| Добавлен | Введен новый слой по умолчанию. |
| Обновлен | Тот же набор данных заменен более новой версией или редакцией из того же источника. |
| Заменен | Слой заменен другим набором данных из того же или другого источника. |
| Переобработан | Исходный набор данных не изменился, но изменился способ его подготовки для ELSA (например, передискретизация, изменение масштаба или маскирование). |
| Переименован | Изменилось только название слоя, отображаемое в инструменте; исходные данные те же. |
| Удален | Слой больше не используется по умолчанию. |

## Планируемые изменения

Изменения, которые ожидаются, но еще не применены. Даты являются ориентировочными и могут измениться.

| Ожидаемая дата | Слой | Тип изменения | Описание | Статус |
|----------------|------|---------------|----------|--------|
| *Подлежит уточнению* | *Подлежит уточнению* | *Подлежит уточнению* | *Подлежит уточнению* | *На рассмотрении* |

## Изменения, внесенные до создания этого журнала

Изменения слоев данных по умолчанию, внесенные до создания этого журнала, все еще собираются. Они будут добавлены в [Историю изменений](#change-history) выше по мере их подтверждения.

## Вопросы о конкретном слое

По вопросам о конкретном слое данных, его источнике или о том, как изменение влияет на существующий анализ, см. [Поддержка и контакты](11_support.md).
