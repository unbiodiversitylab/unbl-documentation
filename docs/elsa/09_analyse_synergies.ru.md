# Анализ синергии и компромиссов

Одним из результатов анализа ELSA является выявление синергии между действиями по достижению целей ГПБ, охватывающих биоразнообразие, изменение климата и благосостояние человека. Анализ измеряет результат каждого планировочного элемента с помощью показателя «представления», чтобы показать, где одновременное планирование по всем целям ГПБ могло привести к тому, что отдельные планировочные элементы представлены в меньшей степени, чем другие. Где, на тематических картах:

$$
\text{Показатель представления} = \frac{\text{Представление на карте действий ELSA}}{\text{Максимальное представление}}
$$

После проведения анализа пользователи могут просмотреть результаты и оценить, привели ли выбранные параметры к приемлемому представлению для каждого из элементов планирования. 

Пользователи могут просмотреть представления элементов, нажав на значок ![Информация](images/icons/info-icon.png){style="display: inline; height: 2em; width: 2em;"} в легенде слоя переключенного анализа. При этом отобразится окно с тестовой информацией, содержащее общую площадь земель, выделенных для каждого природоохранного мероприятия в анализе, а также таблица с весом, общим представлением и индивидуальным представлением для каждого природоохранного мероприятия по каждому элементу планирования.

Пользователи могут также сохранить эту же информацию на своих локальных компьютерах, нажав на кнопку ![Другие действия (три точки)](images/icons/ellipsis-icon.png){style="display: inline; height: 2em; width: 2em; transform: rotate(90deg);"} рядом с записью своего анализа, а затем нажав «Скачать CSV» или «Скачать JSON», в зависимости от желаемого формата. Пользователи также могут нажать «Скачать сводку в формате Excel», чтобы загрузить более полный информационный лист с результатами теста, в котором представлены описания данных и метаданные для каждого планировочного элемента, описания целей политики, использованных для анализа, и ресурсы пространственного анализа приоритетов наряду с оценками представления.

Пользователи могут оценить оценки представления для выбранных ими планировочных элементов и повторно дублировать и запускать дополнительные анализы с увеличенными/уменьшенными весами для планировочных элементов в зависимости от того, хотят ли они увеличить/уменьшить их представление на окончательной карте приоритетных территорий.
