# Попробуйте сначала: практическое упражнение по планированию

Инструмент ELSA предлагает вам задать целевые показатели по площади, веса и коэффициент граничного штрафа. Затем компьютер определяет, где следует разместить каждое действие. На этой странице вы можете сами принять такие же решения на небольшой сетке, прежде чем работать с инструментом на национальных данных. Это займет около десяти минут. Ничего из того, что вы здесь делаете, не сохраняется и никуда не отправляется.

!!! note "Источник"
    Это упражнение основано на *Conservation Planning Exercise* (упражнение по природоохранному планированию), созданном Trevor Wiens, Apropos Information Systems Inc., и размещенном PacMARA и The University of Queensland на сайте [marxansolutions.org](https://marxansolutions.org/getting-started/). Данные на этой странице вымышлены и предназначены для практики.

## Два способа поставить задачу планирования {#two-questions}

Инструменты пространственного планирования отвечают на один из двух вопросов:

| | Минимальная стоимость | Максимальная ценность на доступной площади |
|---|---|---|
| **Вопрос** | Какой самый дешевый набор участков позволяет достичь всех целей? | Где можно обеспечить наибольшую ценность, если для каждого действия отведена фиксированная площадь? |
| **Вы задаете** | Цель для каждого планировочного элемента | Целевой показатель по площади для каждого действия и вес для каждого планировочного элемента |
| **Где используется** | Marxan и целевая функция минимального набора (minimum set) в prioritizr | Инструмент ELSA (целевая функция максимальной полезности (maximum utility) в prioritizr) |

Первая вкладка ниже содержит классическую задачу, на которой учатся многие специалисты по планированию. Вторая представляет собой уменьшенную версию задачи, которую инструмент ELSA решает для вашей страны.

## Упражнение {#exercise}

=== "Минимальная стоимость"

    Каждый квадрат является [планировочной единицей](12_annex1.md#planning-units). У каждой планировочной единицы есть стоимость и определенное количество трех планировочных элементов: A, B и C.

    1. В каждой планировочной единице показаны количества элементов A, B и C и её стоимость. Чтобы видеть только одно значение, выберите его в разделе **Показать на карте**.
    2. Нажимайте на планировочные единицы, чтобы выбрать их, или используйте клавиши со стрелками и пробел. Чтобы отменить выбор планировочной единицы, нажмите на нее еще раз.
    3. Достигните всех целей, указанных в таблице, с как можно более низкой оценкой.
    4. Нажмите **Запустить компьютерный поиск** и **Показать лучшее решение**, чтобы сравнить свое решение с решением компьютера.
    5. Измените **Коэффициент граничного штрафа (BPF)** и попробуйте еще раз. Чем выше BPF, тем больше поощряются компактные группы планировочных единиц.

    <div class="planning-exercise" data-mode="mincost" markdown>
    *Для этого упражнения требуется JavaScript. Если вы его не видите, перезагрузите страницу или попробуйте другой браузер.*
    </div>

    Оценка складывается из трех составляющих. Чем она меньше, тем лучше.

    - **Стоимость**: общая стоимость выбранных планировочных единиц.
    - **Граничный штраф**: BPF, умноженный на длину внешней границы вашего выбора. Длина каждой стороны планировочной единицы равна 10. Стороны, общие для двух выбранных планировочных единиц, не учитываются.
    - **Штраф за недобор**: 100 за каждую единицу цели, которая не достигнута.

    !!! tip "Что это означает в ELSA"
        Инструмент ELSA использует тот же [коэффициент граничного штрафа](05_editing_analysis.md#fig-adjust-bpf), чтобы сделать зоны действий более компактными. Но он не ищет минимальную стоимость. На второй вкладке показано, что он делает вместо этого.

=== "Как в ELSA"

    Здесь к каждой планировочной единице можно применить одно из трех действий: **Охрана**, **Восстановление** или **Управление**. У каждого действия есть [целевой показатель по площади](12_annex1.md#area-based-target): наибольшее число планировочных единиц, которое оно может охватывать. Ваша задача — обеспечить как можно большую взвешенную ценность для четырех планировочных элементов: биоразнообразия, запасов углерода, водообеспечения и средств к существованию.

    1. Выберите действие в разделе **Применяемое действие**, затем нажимайте на планировочные единицы, чтобы применить к ним это действие. Чтобы убрать действие с планировочной единицы, нажмите на нее еще раз.
    2. В разделе **Показать на карте** выберите **Тип земель**. Каждое действие допускается только на некоторых типах земель, как [зоны ограниченных действий](12_annex1.md#action-zones) в ELSA. На городских территориях никакие действия не допускаются, а действие «Охрана» допускается только на нетронутых или деградированных землях.
    3. Существующая охраняемая территория (пунктирный контур) [заблокирована](12_annex1.md#lock-in-features) для действия «Охрана». Блокировку можно отключить.
    4. Выберите **Тепловая карта (взвешенная ценность)**, чтобы увидеть, где взвешенная ценность наиболее высока, как на [тепловых картах](07_viewing_heatmaps.md) в ELSA.
    5. Откройте раздел **Настройки**, чтобы изменить целевые показатели по площади и [веса](12_annex1.md#weights), затем снова запустите компьютерный поиск и посмотрите, как изменится его карта.
    6. Сравните свою карту с результатом компьютерного поиска и с лучшим решением.

    <div class="planning-exercise" data-mode="elsa" markdown>
    *Для этого упражнения требуется JavaScript. Если вы его не видите, перезагрузите страницу или попробуйте другой браузер.*
    </div>

    Каждое действие обеспечивает разную долю каждого элемента. Например, действие «Охрана» обеспечивает всю ценность планировочной единицы для биоразнообразия, но лишь малую часть ее ценности для средств к существованию, а действие «Управление» — наоборот. Оценка равна обеспеченной взвешенной ценности за вычетом граничного штрафа. Чем она больше, тем лучше.

    !!! tip "Что это означает в ELSA"
        Каждая настройка здесь соответствует настройке в инструменте ELSA: целевые показатели по площади, блокировка, веса и коэффициент граничного штрафа (см. [Редактирование запуска анализа ELSA](05_editing_analysis.md)). Инструмент ELSA решает задачу того же типа для каждой планировочной единицы вашей страны, с четырьмя действиями и гораздо большим числом планировочных элементов.

## Почему это делает компьютер {#why-a-computer}

Из сетки в 100 планировочных единиц можно составить 2^100^ различных выборок, то есть примерно миллион в пятой степени (единица с 30 нулями). Никто не смог бы проверить их по одной. В инструменте ELSA страна состоит из десятков тысяч планировочных единиц.

- **Компьютерный поиск** использует метод имитации отжига, который применяется в Marxan. Он вносит множество небольших случайных изменений и сохраняет большинство изменений, улучшающих оценку. Он быстро находит хорошие решения, но каждый запуск дает немного другое решение, и он не может определить, насколько далеко находится от лучшего решения.
- **Лучшее решение** рассчитано с помощью prioritizr — программного обеспечения, на котором основан инструмент ELSA, — с использованием точного решателя. На такой маленькой сетке это наилучшее возможное решение для заданных настроек. Для целой страны инструмент ELSA останавливается, когда его решение отличается от наилучшего возможного не более чем на 5 %, чтобы анализ занимал минуты, а не дни.

Запустите компьютерный поиск несколько раз и сравните его решения с лучшим решением.
