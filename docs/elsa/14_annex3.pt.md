# Anexo 3: Registro de Alterações das Camadas de Dados

Esta página registra as alterações nas **camadas de dados padrão** utilizadas pela Ferramenta de Planejamento Espacial Integrado ELSA. As camadas de dados padrão são as características de planejamento, as restrições de bloqueio (lock-in) e as restrições de zoneamento que o ELSA fornece para uma nova análise. O conjunto atual está listado no [Anexo 2 - Camadas de Dados](13_annex2.md).

As camadas de dados mudam ao longo do tempo: os conjuntos de dados de origem são atualizados pelas instituições que os produzem, conjuntos de dados melhores tornam-se disponíveis e a forma como os dados são preparados para o ELSA evolui. Este registro de alterações permite que os usuários vejam quais camadas mudaram, quando mudaram e por quê, de modo que os resultados produzidos em momentos diferentes possam ser comparados, interpretados e citados corretamente.

!!! note
    As alterações listadas aqui aplicam-se às **novas análises** criadas após a data da alteração. As análises que já foram executadas mantêm as camadas de dados com as quais foram executadas, e seus resultados não são recalculados. Para usar camadas atualizadas, crie uma nova análise.

## Como ler este registro de alterações

Cada entrada descreve uma alteração em uma camada de dados padrão, usando um dos seguintes tipos de alteração.

| Tipo de alteração | Significado |
|-------------------|-------------|
| Adicionada | Uma nova camada padrão foi introduzida. |
| Atualizada | O mesmo conjunto de dados foi substituído por uma versão ou edição mais recente da mesma fonte. |
| Substituída | A camada foi substituída por um conjunto de dados diferente, da mesma fonte ou de outra. |
| Reprocessada | O conjunto de dados subjacente não mudou, mas mudou a forma como é preparado para o ELSA (por exemplo, reamostragem, reescalonamento ou mascaramento). |
| Renomeada | Apenas o nome da camada exibido na ferramenta mudou; os dados subjacentes são os mesmos. |
| Removida | A camada não é mais usada por padrão. |

## Alterações feitas antes deste registro

As alterações nas camadas de dados padrão feitas antes da criação deste registro ainda estão sendo compiladas. Elas serão adicionadas ao [Histórico de alterações](#change-history) acima à medida que forem confirmadas.

## Dúvidas sobre uma camada específica

Para dúvidas sobre uma camada de dados específica, sua fonte ou como uma alteração afeta uma análise existente, consulte [Suporte e Contato](11_support.md).
