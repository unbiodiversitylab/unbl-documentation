Partilhar conjuntos de dados disponíveis na plataforma pública é fácil. Para o fazer:

1.	Ative o(s) conjunto(s) de dados de interesse na visualização do seu mapa.

2.	Copie o URL apresentado no seu browser.

3.	Partilhe! Quaisquer conjuntos de dados da nossa plataforma pública estarão acessíveis a qualquer pessoa, quer seja ou não um utilizador registado.
