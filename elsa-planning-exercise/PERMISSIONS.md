# Permissions for the ELSA planning exercise

The exercise page (`docs/elsa/planning_exercise*.md`) adapts the *Conservation
Planning Exercise* created by Trevor Wiens, Apropos Information Systems Inc.,
hosted by PacMARA and The University of Queensland at
<https://marxansolutions.org/getting-started/>.

**It stays unpublished until every row below is received.** While any ☐ is left
in this file, `scripts/check_docs.py` fails if the page is removed from
`draft_docs` in `mkdocs.yml`, or if the original grid data is added.

When an approval arrives, replace both ☐ in that row with the date, and note the
contact and what was agreed. Keep the correspondence on file.

## What to ask

1. May UNDP/UNBL include an adapted version of the exercise in the ELSA
   documentation, in English, Spanish, French, Portuguese and Russian?
2. The adaptation uses our own invented grid and adds a second, ELSA-style tab
   (area-based targets per action, action zones, lock-in, weights). Is that fine
   as part of the same adapted exercise?
3. Would you like us to offer the original grid data as well? If so, may we
   reuse it, and could you share the source data, target rules, penalty factors,
   boundary settings and selected units for the published Marxan solutions?
4. What licence should apply to the adapted content and code?
5. How would you like to be credited, and which page should we link to?
